## Описание:

Проект "Курсовой проект 1" - создание приложения для анализа транзакций, которые находятся в Excel-файле.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:nikolayvov/Kurs1.git
```

2. Установите зависимости:
```
poetry install
```

## Тестирование:

Юнит-тесты были реализованы с помощью pytest. Покрытие составляет 92%.

Запустить тесты:

```
pytest .
```

Покрытие:

```
pytest --cov .
```
## Страница ГЛАВНАЯ

### Модуль "utils"
```
get_greeting - приветствие
get_cards_data - возвращает общие суммы расходов и кешбэк по каждой карте
get_top_transactions - возвращает топ-5 транзакций по сумме платежа
get_settings - возвращает данные из JSON-файла
get_rates - возвращает курсы валют по API запросу
get_stocks - возвращает стоимость акций по API запросу
```
### Модуль "views"
```
main_page - связывает функциональности модуля utils возвращает JSON-ответ по ТЗ
```
## Простой поиск

transactions_search - возвращает список транзакций, где строка поиска встречается в описании или категории
